# genius-3-1

Genius 論理・表現 II Part III Unit 1「One Small Action — Speech」スピーチ練習アプリ

- `index.html` … ① Model（Yui のスピーチ）シャドーイング・採点（Introduction / Body / Conclusion 別練習、審査員との Q&A ロールプレイ）
- `structure.html` … ② Logic and Structure（Think It Through 穴埋め）・Functions 表現の暗唱・Figure It Out
- `listen.html` … ③ Put It Together（Haruto のスピーチ）ポーズ・強勢を意識した Listen、Recite 採点＋Check Points、Q&A 練習
- `myspeech.html` … ④ Try It Out：トピック選択 → Brainstorming → Outline → 200語原稿 → 発表練習・採点（ブラウザに自動保存）

推奨ブラウザ：Chrome / Edge（音声認識・音声合成を使用）。🎧 ヘッドフォン推奨。

※ 日本語訳、Listen のポーズ・強勢表示、Q&A 解答例はアプリ用に作成した参考例です。
